# TrajetÉquipe — prototype V1

Prototype navigateur en un seul fichier HTML.

## Tester
1. Décompressez l'archive.
2. Ouvrez `index.html` dans un navigateur récent.
3. Testez la création de groupe et la saisie d'un code d'invitation.

## Limites importantes
- Prototype d'interface uniquement : aucune base de données ni authentification réelle.
- Les codes d'invitation sont générés localement et ne permettent pas de rejoindre un groupe depuis un autre appareil.
- Les statistiques de l'exemple sont fictives.
- Aucun paiement, géolocalisation ou envoi de notification n'est actif.

## Étape technique suivante
Créer le backend, les comptes utilisateurs, les règles d'accès multi-entreprises, la persistance PostgreSQL, puis les modules trajets et comptabilité avec tests automatisés.
